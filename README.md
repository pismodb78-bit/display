# Школьное расписание

Программа для большого сенсорного экрана в коридоре: показывает расписание
уроков и позволяет учителю править его прямо на месте — или с любого
компьютера в школьной сети.

* **Два расписания сразу.** Обычное (постоянное) и изменённое — на случай,
  когда учитель заболел, а трогать основной график не хочется. Переключаются
  одной кнопкой, целиком или только на выбранный день.
* **Два вида показа.** Неделя одного класса или все классы на один день.
* **Календарь.** Любая дата, следующий день, праздники и каникулы —
  их отмечает учитель, и в такие дни на экране написано, что уроков нет.
* **Замена на горячую.** Учитель нажал «Применить» у себя в кабинете —
  телевизор переключился сам за несколько секунд. Никто ни к чему не
  подходит и ничего не перезапускает.
* **Заливка расписания файлом.** То, что уже набрано в Excel, загружается
  за минуту (CSV) — и так же выгружается обратно.
* **Две темы.** Тёмная для телевизора в коридоре и светлая для кабинета;
  переключается там же, где всё остальное, и доезжает до экрана сама.

Написано на C# / WinForms (.NET 8), формы открываются и правятся в
конструкторе Visual Studio. Данные — MySQL (MAMP, phpMyAdmin), тот же
подход, что в PISMO: программа ходит в базу напрямую, а адрес лежит в
`ip.txt` рядом с `.exe`.

## Быстрый старт

### 1. База

В MAMP запустить MySQL, открыть phpMyAdmin и создать базу `school_schedule`
(сравнение `utf8mb4_unicode_ci`). Таблицы программа заведёт сама при первом
запуске.

Если у пользователя базы нет прав на `CREATE` — загрузить
[`sql/school_schedule.sql`](sql/school_schedule.sql): phpMyAdmin → база →
вкладка **SQL** → вставить файл → «Вперёд».

Пользователю нужно разрешить вход **по сети**, а не только с локальной
машины (в MAMP — `Tools → phpMyAdmin → Учётные записи`, хост `%` или
подсеть школы):

```sql
CREATE USER 'user1'@'%' IDENTIFIED BY 'scent01';
GRANT ALL PRIVILEGES ON school_schedule.* TO 'user1'@'%';
FLUSH PRIVILEGES;
```

### 2. `ip.txt`

Лежит рядом с `SchoolSchedule.exe`, правится Блокнотом:

```
server   = 192.168.0.20
port     = 3306
uid      = user1
password = scent01
database = school_schedule

admin = 1234          # пароль на вход в режим учителя

# theme = dark        # dark / light. Пусто — как выбрано в программе;
                      # строка здесь перебивает выбор для этого компьютера
fullscreen = 1        # 1 — во весь экран (телевизор), 0 — обычное окно
scale      = 1.0      # масштаб шрифтов: 1.3 — крупнее на треть
refresh    = 10       # как часто проверять базу, секунд
```

Файл перечитывается **на ходу**: сохранили — программа сама переподключится.
Понимается и однострочный вид, как в PISMO:
`server=192.168.0.20;port=3306;uid=user1;password=scent01;database=school_schedule`

Те же настройки можно поменять пальцем: **Учитель → Доступ → Подключение к
базе** — программа перепишет `ip.txt`, сохранив комментарии.

### 3. Запуск

Скопировать папку `publish` на компьютер за телевизором и запустить
`SchoolSchedule.exe`. Классов сначала нет — на экране будет написано, что
делать: нажать **«Учитель»**, ввести пароль (по умолчанию `1234`) и
добавить классы на вкладке «Классы».

**Пароль после установки нужно сменить** — вкладка «Доступ». Новый хранится
в базе хешем; строка `admin` в `ip.txt` остаётся запасным входом на случай,
если пароль забыли (тогда достаточно удалить строку `admin_password` из
таблицы `settings`).

## Экран в коридоре

```
┌──────────────────────────────────────────────────────────────────────┐
│ Гимназия №5        Вторник, 26 августа 2026 · завтра  ● база   14:32 │
│                    Все классы · Вторник                              │
├──────┬──────────┬──────────┬──────────┬──────────┬──────────────────┤
│ Урок │    5А    │    5Б    │    6А    │    6Б    │       7А         │
│  1   │Математика│ Русский  │ История  │ Физика   │   Литература     │
│8:30  │Иванова   │Петрова   │Смирнов   │Кузнецов  │   Петрова        │
├──────┼──────────┼──────────┼──────────┼──────────┼──────────────────┤
│  2   │ Русский  │Математика│ ...      │          │                  │
├──────┴──────────┴──────────┴──────────┴──────────┴──────────────────┤
│ [Выбрать класс][Показать неделю] [◀][Сегодня][▶][Календарь]  [Учитель]│
└──────────────────────────────────────────────────────────────────────┘
```

* Идущий сейчас урок подсвечен — время берётся из звонков.
* Замены (отличия изменённой сетки от обычной) горят оранжевым с полоской
  слева; отменённые уроки подписаны «нет урока».
* Тычок в колонку класса открывает его неделю, тычок в колонку дня —
  этот день у всех классов.
* Если экрана не касались, через пару минут он сам возвращается к тому,
  что назначил учитель (время — «Показ → вернуться к этому показу через»).
* Кнопка «Учитель» скрыта не полностью: три быстрых касания заголовка
  открывают тот же вход по паролю.

Программа не даёт случайно закрыть себя пальцем: в полноэкранном режиме
Alt+F4 не работает. Выход — **Учитель → Доступ → Выйти из программы** или
`Ctrl+Shift+Q` (тоже спросит пароль). `F5` — перечитать базу немедленно.

### Автозапуск на телевизоре

Ярлык на `SchoolSchedule.exe` положить в
`shell:startup` (Win+R → `shell:startup`). Отдельно стоит отключить
спящий режим и заставку в параметрах питания Windows.

## Два расписания

| | Обычное | Изменённое |
|---|---|---|
| Зачем | постоянный график на четверть | замены: заболел учитель, актовый день |
| Где правится | «Расписание» → кнопка «Обычное» | «Расписание» → кнопка «Изменённое» |
| Как показать | «Показ» → «Обычное» | «Показ» → «Изменённое» |

Обычный порядок работы такой:

1. Один раз набрать (или залить файлом) **обычное** расписание.
2. Когда понадобилась замена — «Копировать обычное → изменённое», поправить
   в изменённой сетке те клетки, которые меняются.
3. Нажать «Изменённое» на вкладке «Показ». Экран переключится сам.
4. Замена кончилась — нажать «Обычное». Основной график всё это время
   лежал нетронутым.

**Замена на один день, не трогая остальные.** Вкладка «Календарь» → выбрать
число → «Какое расписание показывать в этот день» → *изменённое* →
«Сохранить отметку». В этот день экран покажет изменённую сетку, во все
остальные — обычную, и общий переключатель трогать не нужно.

## Календарь и праздники

На вкладке «Календарь» у каждой даты можно поставить:

* **Праздник или каникулы** — вместо таблицы на экране будет надпись
  «День знаний — уроков нет». Отмеченные дни в календаре видны жирным.
* **Название** — что именно за день.
* **Свою сетку** — обычную или изменённую, только на это число.

Праздники учитываются и в режиме «ближайший учебный день»: в пятницу
вечером экран покажет понедельник, а если понедельник — праздник, то
вторник.

## Показ: что можно назначить

Вкладка «Показ» — это то, что видит телевизор, когда его никто не трогает.

| Настройка | Смысл |
|---|---|
| Что показывать | все классы на день / неделя одного класса |
| За какой день | сегодня · завтра · ближайший учебный · выбранная дата |
| После времени — завтрашний день | например `14:30`: после уроков экран сам переключается на завтра |
| Какое расписание | главный переключатель: обычное / изменённое |
| Заголовок | название школы в шапке |
| Объявление | строка внизу экрана; длинная — едет справа налево |
| Размер сетки | сколько уроков, учебных дней (5 или 6), классов на экране |
| Листать само | по очереди показывать страницы классов |
| Замены | подсвечивать оранжевым отличия от обычного расписания |
| Цвета экрана | тёмные (для телевизора) или светлые |

Кнопка **«Применить и показать на экране»** сохраняет всё сразу; кнопки
«Обычное»/«Изменённое» срабатывают мгновенно, не дожидаясь её.

## Правка с другого компьютера

Расписание не обязательно набивать у телевизора. На любом компьютере в той
же сети:

1. Скопировать туда папку с программой.
2. В `ip.txt` указать адрес школьного сервера (тот же, что на телевизоре).
3. Дописать строку:

   ```
   mode = editor
   ```

   Программа откроется сразу окном учителя, без полноэкранного показа.
   То же самое даёт ключ в ярлыке: `SchoolSchedule.exe /editor`.

Всё, что там меняется, ложится в общую базу, и телевизор подхватывает
правку в течение `refresh` секунд.

### Заливка расписания файлом

«Расписание» → **«Загрузить из файла…»**. Формат — обычный CSV, такой
Excel отдаёт по «Сохранить как → CSV (разделители — точки с запятой)»:

```
Класс;День;Урок;Предмет;Учитель;Кабинет
5А;Понедельник;1;Математика;Иванова И. И.;204
5А;Понедельник;2;Русский язык;Петрова А. С.;112
5Б;Вторник;1;Физкультура;Сидоров П. П.;спортзал
```

* День пишется как «Понедельник», «Пн» или числом 1…7.
* Классов, которых ещё нет, программа заведёт сама.
* Спросит, заменить сетку целиком или добавить к тому, что уже есть.
* Кодировка определяется сама — и UTF-8, и то, что сохраняет русский Excel
  (1251). Разделитель тоже: `;`, `,` или табуляция.
* Строки, которые разобрать не вышло, будут перечислены — остальные
  загрузятся.

Пример файла: [`sql/пример_расписания.csv`](sql/пример_расписания.csv).

Кнопка **«Сохранить в файл…»** делает обратное — выгружает сетку в CSV
(его можно открыть в Excel двойным щелчком).

## Сборка .exe

**В Visual Studio:** открыть `SchoolSchedule.sln` → F5. Формы правятся в
конструкторе как обычно.

**Одним файлом для телевизора:** запустить `Собрать exe.bat` (нужен
[.NET SDK 8](https://dotnet.microsoft.com/download)). Получится
`publish\SchoolSchedule.exe`, которому не нужен установленный .NET —
папку `publish` можно просто скопировать на нужный компьютер.

**Без установки студии:** после пуша в ветку GitHub сам собирает .exe —
вкладка **Actions** → «Сборка .exe» → архив
`SchoolSchedule-win-x64` внизу страницы.

## Если что-то не работает

| На экране | Что делать |
|---|---|
| «Сервер … не отвечает» | MAMP запущен? Тот ли IP в `ip.txt`? Проверить `ping`. В брандмауэре Windows на сервере открыть порт 3306 |
| «Сервер не принял логин или пароль» | Проверить `uid` и `password` в `ip.txt` |
| «На сервере нет базы …» | Создать базу в phpMyAdmin и загрузить `sql/school_schedule.sql` |
| «Сервер не разрешает подключаться с этого компьютера» | Пользователю нужен хост `%`, а не `localhost` (см. «Быстрый старт») |
| Пароль учителя забыт | В phpMyAdmin удалить строку `admin_password` из таблицы `settings` — снова заработает `admin` из `ip.txt` |
| Мелкий текст на большом экране | `scale = 1.3` в `ip.txt` (сохранить — подхватится само) |
| Тёмный экран слишком мрачный для холла | «Показ» → «Цвета экрана» → светлые. Для одного компьютера — `theme = light` в его `ip.txt` |
| Правки не доезжают до телевизора | Проверить, что там в шапке «● база на связи»; `refresh` в `ip.txt` задаёт задержку |
| Загруженный CSV в «кракозябрах» | Сохранить из Excel как «CSV UTF-8» либо обычный CSV — оба варианта читаются, но не «Юникод (текст)» |

Ошибки пишутся в файл `ошибки.log` рядом с `.exe`.

## Как это устроено

```
Core/     AppConfig (ip.txt), Db, Schema, Repo, ScheduleResolver,
          DisplaySettings, CsvSchedule, PasswordHasher, Ui, Ru
Controls/ OnScreenKeyboard (экранная клавиатура), NoFocusButton
Forms/    DisplayForm   — витрина на телевизоре
          EditorForm    — окно учителя (расписание, классы, звонки,
                          календарь, показ, доступ)
          PasswordForm, ClassPickerForm, DatePickerForm,
          LessonEditForm, CopyDayForm, ConnectionForm
sql/      school_schedule.sql, пример_расписания.csv
```

Таблицы: `classes`, `lesson_times`, `schedule` (обе сетки, поле `variant`),
`calendar_days`, `settings` — с комментариями в
[`sql/school_schedule.sql`](sql/school_schedule.sql).

**Про темы.** Палитра живёт в `Core/Ui.cs` двумя наборами цветов; формы
берут цвета оттуда в своём `ApplyTheme()`. Переключение — это смена набора
и повторный вызов `ApplyTheme()`, без перезапуска. Выбор хранится в
`settings.theme`, поэтому доезжает до телевизора тем же счётчиком правок,
что и расписание; строка `theme` в `ip.txt` перебивает его для отдельного
компьютера.

**Про горячую замену.** Программа на телевизоре не хранит у себя, что
показывать: всё лежит в `settings`. Раз в `refresh` секунд она спрашивает
у базы одно число — `settings.revision`, счётчик правок, — и перечитывает
расписание, только когда оно выросло. Любая запись из окна учителя этот
счётчик увеличивает. Поэтому нагрузки на сервер почти нет, а замена
доезжает до экрана сама.

**Про пароль.** В базе лежит не пароль, а `pbkdf2$100000$…` —
PBKDF2-HMAC-SHA256, как в PISMO. Заглянувший в phpMyAdmin ученик пароля
не увидит. После пяти неверных попыток ввод замирает на полминуты.
